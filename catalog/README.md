# Партнёрка коротких видео — файлы для рассылки

Сайт не нужен. Рабочая схема:

1. **Клиенту / автору** кидаешь `out/partnerka-katalog.pdf` в Telegram.
2. **Себе** держишь `out/partnerka-katalog.xlsx` — там фильтры по типу, ГЕО, модели оплаты.
3. **Баннеры** складываешь ZIP-папками на Яндекс.Диск и вставляешь ссылку в столбец «Баннеры».

## Собрать заново

```bash
python3 catalog/build_catalog.py
```

Список офферов правится в `catalog/offers.py`.
