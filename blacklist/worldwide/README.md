Do not browse these files as a catalog. They exist only so `../filter-list.py` can delete matches from your list.

- `domains.txt.gz` — 7,030,450 unique domains (malware + phishing + RKN/mirrors)
- `banned-rkn-mirrors.txt.gz` — 1,687,056 banned/mirror/closed domains
- `domains-core.txt.gz` — 270,965 higher-signal IOC domains
- `urls.txt.gz` — 147,509 malware/phishing URLs
- `github-repos.txt` — 7,654 FakeGit / SmartLoader repositories
- `github-owners.txt` — 7,219 campaign GitHub accounts
- `campaign-domains.txt` — 2026 fake-installer and TDS domains
- `ips.txt` — a few confirmed campaign hosts
- `STATS.txt` — per-source counts

Use `--mode full` or `--mode core` on the filter script.
