## Что реально могут живые сборщики

**Магазины и отзывы (6)**  
Забрать карточки товаров и отзывы: Amazon, Myntra, G2, Rebecca Minkoff, общий интернет-магазин. На выходе список цен/текстов.

**LinkedIn (3)**  
Забрать вакансии или контакты из Sales Navigator. По имени — таблица вакансий/людей, не «официальный API».

**Facebook (3)**  
События, список подписок, посты по хештегу. Маркетплейс был — ссылка уже мёртвая.

**Instagram / Linktree (2)**  
Посты по хештегу; ссылки с визитки Linktree.

**YouTube / видео (4)**  
Пересказ ролика, качать/разобрать видео, собрать почты из описания канала.

**Картинки (2)**  
Забрать картинки из Google и с веба пачкой.

**Объявления (3)**  
Жильё Immobiliare, авто Autoscout24, аукцион Savills. На выходе лоты и цены.

**Новости (3)**  
Заголовки Google News, Indian Express, лента OSINT.

**Справочники (5)**  
Адвокаты (2), дайв-сайты, библиотека GSA, блокчейн-транзакции. Забрать строки из каталога.

**OSINT-наборы (7)**  
Пачка инструментов «найти человека/аккаунт по открытым данным». Не один сайт, а комбайн.

**Универсальный краулер (10)**  
«Скрейпь что скажут»: flarecrawl, scrape-rs, Scrapy, spa-crawler. Сами по себе без цели — движок.

**Узкие штуки (7)**  
Подарки Telegram; спортивный рекрутинг; подписки на GitHub; WhatsApp-чат + скрейп; cookies из Gemini (это уже не обычный парсер, ближе к краже сессии); плюс 4 с мусорным именем, цель неясна.

## Что не сборщик сайта (15) — из рабочей коробки убрал

Разбирают **свой файл**, не чужой сайт: резюме, PDF, счета, OCR, SQL, HTML-библиотека, DMARC, землетрясения, VR-сцена, FPGA. Parser в имени есть, данных с Amazon/LinkedIn не заберут.

## Мёртвые (8)

Страница GitHub не открывается: общий скрейпер, crawlbase, индексы Чили, Facebook Marketplace, больницы Германии, превью YouTube без ссылки.
