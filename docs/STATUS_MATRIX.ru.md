# Матрица статусов Excel

Колонка **`status`** (алиас: `last_run_status`, `статус`) на листе «Аккаунты» — **итог по аккаунту за прогон** (сводка). Лист **Log** — статус **каждой попытки** (те же русские подписи).

| Ситуация | Log / попытка | Строка аккаунта (сводка) | Файл |
|----------|---------------|---------------------------|------|
| Успех TikTok | опубликовано | опубликовано (если все ok) | → posted/ |
| dry-run | тест без публикации | тест без публикации | → posted/ |
| Нет login | нет входа | нет входа (приоритет) | не move |
| Captcha | капча | капча | не move |
| Rate limit | лимит TikTok | лимит TikTok | не move |
| Fail confirm | нет публикации | нет публикации / частично | → failed/ |
| Ledger duplicate | уже опубликовано | уже опубликовано | → posted/ |
| Нет mp4 | нет видео | нет видео | — |
| Dolphin | ошибка Dolphin | ошибка Dolphin | — |
| 1/2 ok | по строкам Log | частично опубликовано (1/2) | — |

`last_run_error` — технический текст (detail). При закрытом Excel статусы в pending → `sync-excel`.
